# rxz · roblox-thumbnail

A skill for your AI agent that makes Roblox thumbnails that survive the Discover feed — not another
"AI slop generator".

It interviews you first, writes the art prompt, composites the title in a real font, and grades the result at
256 px. No API key. No subscription. No watermark.

```
onboarding  →  brief  →  archetype  →  prompt  →  art  →  title  →  check  →  compare
```

---

## Why this exists

Most AI thumbnails fail for one reason: they are 1920 px pictures designed for a 256 px slot. Three characters,
flat light, six colours and four words of garbled text look fine full-screen and turn to mush in the feed.

This skill enforces the opposite, and it asks before it draws:

- **One subject**, one prop, one promise.
- **A face with an emotion** you can name from across the room.
- **One key light and one rim** — not "dramatic lighting".
- **One to three words**, composited afterwards, never generated by the image model.
- **A 256 px proof** you have to look at before calling it done.

## Install

You need an agent that reads `SKILL.md` (Claude Code, Codex, Cursor, Freebuff — anything with a skills folder),
Python 3.10+ and Pillow.

**Claude Code, macOS / Linux / Git Bash**

```bash
bash install.sh
```

**Claude Code, Windows**

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

Both copy this folder to `~/.claude/skills/roblox-thumbnail` and back up an older copy first.

**Any other agent**

Point it at `SKILL.md`, or copy the folder into that agent's skills directory. Nothing here is Claude-specific.

**Python dependency**

```bash
pip install pillow
```

On Windows use `py` wherever this README says `python`.

## First run

```
make me a thumbnail for my game
```

The agent will ask seven questions. Answer them — especially **who the hero is** and **what words go on the
image**. Those two cannot be guessed, and guessing them is how a pet simulator ends up advertising a sword fight.

If you have a screenshot of your own character, game or build, send it. A real screenshot with bad lighting beats
an invented character every time.

---

## What it asks

| Question | Why it matters |
|---|---|
| Game name and link | It reads the store page instead of making you summarise |
| Genre | Picks the archetype and palette |
| The first minute of play | That is the promise the image has to show |
| Who or what is the hero | Identity. It will ask for a file, not a description |
| Theme and feeling | Neon night, grimy horror, candy pastel — and one emotion |
| Words on the image (0–3) | No text is a valid, often better, answer |
| References and bans | Two you love, two you hate, anything that must not appear |

Then it shows you a seven-line art-direction card. Fix the card before it generates; fixing the card is cheap.

## The tools, if you want to drive them yourself

```bash
python scripts/thumb.py init "My Game"                 # fresh brief
python scripts/thumb.py compose brief.json art.png     # 1920x1080 + proofs
python scripts/thumb.py check thumbnail.png            # measured warnings
python scripts/thumb.py sheet a.png b.png c.png        # compare at tile size
```

- `compose` auto-fits the title, keeps it out of the outer 6% and the bottom-right chrome corner, adds a scrim only
  when the art under the text is too bright, and prints the cap height and contrast it achieved.
- `check` prints PASS / WARN / FAIL with the number behind each. WARN is a question, not a verdict — answer it by
  looking.
- `sheet` is the only honest way to choose between candidates: true tile width, colour and greyscale.

`--text-only` writes the transparent type layer for Canva, Photopea or Photoshop.

## Do and don't

**Do**

- Show the loop, not the lore.
- Keep the title to one to three words, in the lower-left or upper-left.
- Give the hero a rim light and a contact shadow.
- Rotate the ten thumbnail slots: hero, gameplay proof, reward, action, stakes.

**Don't**

- Let the image model write text. Ever.
- Put anything important in the bottom-right corner.
- Use three or more characters, or the same face twice.
- Add a watermark or maker's mark to the art.
- Upscale a 512 px image "because it is only a thumbnail".

`references/slop-tells.md` has the full catalogue and the fixes.

## FAQ

**Does it generate the image?**
It uses whatever image tool your agent has. If the agent has none, it gives you the finished prompt and the
settings, and you paste it into your generator of choice. It will never draw the art in code — that is the fastest
route to a placeholder-looking thumbnail.

**Does it work for game icons or banners?**
This version is thumbnails only: 16:9, 1920×1080.

**Can I change the fonts?**
Yes. Drop another font into `assets/fonts/` and point `FONTS` in `scripts/thumb.py` at it. The bundled three are
Anton, Barlow Condensed and Inter, all SIL OFL.

**Why no rxz mark on the image?**
Watermarks cost clicks and read amateur. The brand lives here, in the skill, where it belongs.

**Can I sell thumbnails made with it?**
Use it freely, including for client work. Share the folder as you received it; don't resell it as your own skill.
The fonts are under the SIL Open Font License — see `assets/fonts/FONTS.md`.
